# SimParamEditor

SimParamEditor 是一款基于 Qt Widgets 的仿真参数模板编辑器，可以帮助开发与测试团队维护大规模的结构化参数集合、生成 C++ 代码以及导出运行时所需的 JSON 描述。应用在 macOS / Windows / Linux 上都可通过 CMake 与 Qt 5.5+ 构建运行。

---

## 功能亮点

- **模板建模**：左侧树 + 中央画布联动展示参数结构，支持 struct、enum、标量、定长 char 数组等类型并允许任意层级嵌套。
- **实例管理**：实例与模板分栏展示，可批量创建、复制、导入实例并通过 `InstancesSelectDialog` 进行生成范围筛选。
- **实时校验**：`core/validation.*` 会检测命名规范、重复字段、数组长度等问题，状态栏实时提示结果。
- **代码与数据生成**：`generator/cpp_generator.*` 将模板与实例写入统一的 `Types.h`、`Instances.cpp` 以及 JSON 文件，保证内外一致。
- **主题与快捷操作**：`ThemeManager` 提供亮/暗主题切换，常用操作（新建/打开/保存/生成/删除/重命名）均绑定快捷键。
- **JSON I/O**：`core/json_io.*` 支持将整棵模板或实例树导入/导出为约定格式的 JSON，便于版本控制与集成。

## 构建 & 运行

1. 准备依赖：安装 Qt (5.5 及以上 Widgets 组件) 与 CMake (3.5+)。
2. 生成构建目录（示例为 Debug 模式）：

   ```bash
   cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt -DCMAKE_BUILD_TYPE=Debug
   ```

3. 编译：

   ```bash
   cmake --build build --config Debug
   ```

4. 运行应用：

   ```bash
   ./build/SimParamEditor             # Windows/macOS 可执行文件
   ```

如仅需重新生成 Qt MOC/UI 文件，可执行 `cmake --build build --target SimParamEditor_autogen`。

## 快速上手

1. 启动应用 → 点击 `新建`，使用左侧树添加 struct/字段，右侧属性面板修改类型、单位与默认值。
2. 切换到 “实例” 标签，基于模板创建实例，使用实例滚动区域调整 overrides。
3. 通过顶部 “生成代码”/“生成实例” 按钮分别输出头文件与实例初始化文件；使用 “生成实例” 同时会写出 JSON 模板。
4. 点击 “主题” 切换亮/暗色，确保 UI 与设计稿一致后再保存 `.spe`。

### 4.4 校验机制

#### 实时校验 (输入时)

- 变量名不能为空
- 变量名不能重复（同级检测）
- 数值范围检查（uint16: 0-65535）
- 枚举项不能为空

#### 完整校验 (生成前)

- 所有参数必填项完整
- 无命名冲突
- 无循环依赖
- 类型兼容性检查

### 5.3 撤销/重做机制

使用 Qt Undo Framework:

```cpp
class AddParameterCommand : public QUndoCommand {
public:
    void undo() override {
        model->removeParameter(index);
    }
    void redo() override {
        index = model->addParameter(parent, data);
    }
private:
    ParamModel* model;
    QModelIndex parent;
    QModelIndex index;
    ParamMetadata data;
};

// 使用
QUndoStack undoStack;
undoStack.push(new AddParameterCommand(model, parent, data));
```

## 开发进展（2025-10-11 17.45 更新）

- 架构与构建

  - 树 + 卡片联动，卡片可展开/折叠（结构递归）。
  - 右侧表单：名称、类型（含 enum/char[] 特殊项）、单位、默认值、描述。
  - 枚举编辑：
    - “编辑枚举项”对话框：支持名称 + 数值，添加/更新/删除、自动递增，保证后项值大于前项值。

    - 当字段类型为 struct 或 enum 时，可通过“复用引用”下拉直接引用已存在的结构或枚举（如根下 a/b/c）。
    - 被引用时，该字段不再编辑自身 children/enumItems，而是以引用源为准；避免“重新设计”造成歧义。
    - 在实例编辑中，禁止创建/修改结构体或枚举定义，仅能填写值（遵循模板/引用源）。
  - 保存/打开 `.spe`：包含 `parameters` 与 `instances`；保存/生成前校验阻断。
  - 代码生成（模板）：每个 struct 输出 `.h/.cpp`，包含递归子结构支持。

  - 中间画布实例编辑器：按结构分组渲染；叶子字段可编辑。

## 优化日志（2025-11-19）

### 核心重构完成

1. **类型系统重构 (Type System Refactoring)**
    - 引入 `TypeManager` 单例，统一管理 Struct/Enum 类型。
    - UI 支持新建/引用全局类型，解决了“匿名 Struct”导致的悬空引用风险。
    - 更新了 `MainWidget` 的表单逻辑，在切换类型为 Struct/Enum 时必须指定 `typeName`。
    - `.spe` 项目文件新增 `types` 节点，保存 `TypeManager` 注册的所有类型，打开项目时自动还原类型库，彻底杜绝“重启后引用丢失”。

2. **实例数据模型重构 (Instance Model Refactoring)**
    - `InstanceMetadata` 移除了递归的 `children` 结构。
    - 改为扁平化的 `Diff Model`：`QMap<QString, QVariant>` 存储所有修改过的叶子节点值。
    - 优点：模板结构修改后，实例数据自动适应，不再需要复杂的同步逻辑。
    - 序列化/反序列化逻辑已更新，向下兼容。

3. **代码生成增强 (Code Gen Enhancement)**
    - 更新 `CppGenerator` 以支持 `TypeManager`。
    - 生成代码时会遍历所有注册的类型并生成对应的 `.h` 文件，解决了类型依赖问题。
    - 实例初始化代码 (`renderAggregateInit`) 更新为支持 Diff Model，递归解析 `typeName`。

4. **校验机制更新**
    - `validateProject` 现在会检查 `typeName` 是否存在于 `TypeManager` 中。

### UI 现代化新增（2025-11-20）

- **枚举编辑器重构**：右侧属性面板使用表格直接编辑枚举项（名称/数值），支持即时增删和默认值切换，取消了原有弹窗与多按钮操作，逻辑更直观。
- **Property Browser 自适应**：模板视图默认按列内容自动调整宽度并拉伸说明列，初始化即能完整展示层级信息，避免长文本被硬性换行。
- **PowerShell 构建修复**：清理遗留的 Enum 编辑对话框引用，统一使用右侧表格编辑；同时替换 Qt 5.5 未提供的 `QVector::constLast()` 为兼容写法并补全信号屏蔽逻辑，已在 MSVC 2015 x64 Release 构建中验证通过。

### UI 现代化需求（2025-11-19）

- **设计目标**
  - 统一视觉语言：保持模板/实例两套编辑流程的认知一致性，遵循 “信息优先 / 操作可视 / 反馈即时” 三大原则。
  - 支持多主题：默认亮色，提供深色主题切换；主题切换需在 200ms 内完成，控件状态一致。
  - 自适应布局：1366×768 以上宽屏为主，需兼容 1200px 最小宽度；右侧属性面板可折叠。

- **布局与导航**
  - 顶部工具条：采用扁平化按钮 + 图标（Material Symbols），增加 “生成” 下拉菜单，提供最近项目入口。
  - 左侧 `QTabWidget`：tab 采用 pill 样式，提供搜索框与过滤标签。
  - 中间区域：弃用大块卡片，改为 Property Browser 风格（`QTreeView + QStyledItemDelegate`），支持列宽拖拽与键盘导航。
  - 右侧属性：改用 `QStackedWidget` + 卡片式分组（基础信息 / 类型配置 / 约束 / 说明），提供折叠与浮动提示。

- **组件与交互**
  - 表单控件：统一高度 32px，圆角 4px，Focus 有描边；数值型优先 `QSpinBox/QDoubleSpinBox`，枚举使用支持搜索的 `QComboBox`。
  - 操作反馈：保存/生成等关键动作使用顶部 Inline Toast（3s 自动消失），错误使用右下角红色吐司 + 链接跳转问题节点。
  - 拖拽与排序：在 Tree / Property Browser 中加入插入指示线与 placeholder，撤销可通过 Ctrl+Z 完成。

- **视觉规范**
  - 颜色：主色 #1F6FEB（操作）、辅色 #0D1117（深色背景）、语义色遵循 Material 体系（Success #3FB950 / Warning #D29922 / Error #F85149）。
  - 字体：中文默认 思源黑体 Medium 14px，英文/数字 Roboto 13px；代码/路径使用等宽字体 `JetBrains Mono` 12px。
  - 阴影与圆角：卡片阴影 rgba(15,23,42,0.12) 0 8px 24px，圆角 8px；控件圆角 4px。

- **反馈与动效**
  - Tab 切换、属性展开、树节点折叠使用 120ms 缓动动画（QEasingCurve::OutCubic）。
  - Loading 状态统一用线性进度条叠加在工具条下方；耗时操作提供 “取消” 按钮。
  - Hover/Press 状态颜色遵循主色透明度递进（Hover 8%，Press 16%）。

- **技术落地**
  - 样式：集中管理 QSS 变量（色值、半径、间距），使用 `:root` 自定义属性 + C++ 注入，便于主题切换。
  - 图标：统一加载 `qrc:/icons/` SVG，提供 `IconHelper::getPixmap(color, size)` 工具，减少重复代码。
  - 组件化：抽象 `PropertySectionWidget` / `CommandBar` / `PillTabBar` 等复用控件，放在 `ui/` 目录。

- **实施阶段**
  1. **Design Tokens**：落地颜色/字体/半径/阴影/间距变量，完成 QSS 基础文件。
  2. **结构改造**：替换中间画布为 Property Browser，重构右侧属性面板。
  3. **交互增强**：实现拖拽、Toast、快捷键视觉反馈，接入 Undo/Redo。
  4. **主题与动画**：补全深色主题、统一动效、完善 Loading/空态组件。
